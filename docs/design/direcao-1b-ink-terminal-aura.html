8.3 Método de Euler

Aqui está uma maneira de organizar as 10 aproximações arredondadas para 5 casas decimais. Observe que cada entrada na última coluna torna-se a próxima entrada na terceira coluna.

Isso é semelhante ao método de Newton, no qual cada aproximação sucessiva é usada para encontrar a seguinte. Assim, nesse caso, podemos comparar o valor aproximado de y(x) produzido pelo método de Euler com a aproximação decimal dos valores exatos.

n xₙ yₙ yₙ₊₁
0 0,0 2,00000 2,20000
1 0,1 2,20000 2,41000
2 0,2 2,41000 2,63100
3 0,3 2,63100 2,86410

Como procedimento prático, o erro absoluto em uma aproximação produzida pelo método de Euler é aproximadamente proporcional ao tamanho de passo. Assim, reduzindo o tamanho do passo pela metade reduzem-se os erros.

Observe que o erro absoluto tende a crescer quando x se afasta de x₀.

06 · capturar: resumo da configuração em linha de comando

Aura de captura: como se comporta

Movimento só onde há ação. A ordem garante que a aura nunca entre na imagem salva.

t = 0 ms

1. Captura limpa

A bolha some e o quadro é capturado sem nenhum efeito na tela. É esta imagem que vira a página do livro.

t ≈ 150–900 ms

2. Aura percorre a borda

O gradiente da marca contorna a área recortada (ou a tela inteira) e se apaga. Confirma "salvou" sem texto nem som.

modo automático

3. Bolha viva

Enquanto o automático trabalha, a borda da bolha gira devagar. Parada = pausado. Âmbar fixo = aviso (página repetida, tela preta).

⌕ aproximação
foco

4. Busca acesa

O mesmo gradiente, bem mais lento, marca o campo de busca em foco. É o único outro lugar onde a aura aparece, para não banalizar.

Especificação da aura

cores (claro)  #B0602C → #E0A040 → #C8566A → #7A5AC8 → #3E8C7A
cores (escuro) #D58E55 → #F2BE5C → #E07A8A → #9C82E8 → #5FB59E
borda 3dp + halo com blur de 14dp a 55% · varredura de 750 ms ease-out · giro da bolha em 2,6 s linear · busca em 6 s
Compose: Brush.sweepGradient + rotação animada (InfiniteTransition) num overlay desenhado só após o frame salvo
acessibilidade: "reduzir animações" do sistema → só um contorno estático de 400 ms

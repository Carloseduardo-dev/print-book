8.3 Método de Euler

Aqui está uma maneira de organizar as 10 aproximações arredondadas para 5 casas decimais. Observe que cada entrada na última coluna torna-se a próxima entrada na terceira coluna.

Isso é semelhante ao método de Newton, no qual cada aproximação sucessiva é usada para encontrar a seguinte. Assim, podemos comparar o valor aproximado com a aproximação decimal dos valores exatos.

n xₙ yₙ yₙ₊₁
0 0,0 2,00000 2,20000
1 0,1 2,20000 2,41000
2 0,2 2,41000 2,63100

Como procedimento prático, o erro absoluto em uma aproximação produzida pelo método é aproximadamente proporcional ao tamanho de passo.

Reduzindo o passo pela metade, reduzem-se os erros pela metade, o que é típico de métodos de primeira ordem.
